# Contributing to AgentMesh

We welcome contributions to AgentMesh!

## How to contribute

1. Open an issue describing the bug or feature.
2. Fork the repository and create a topic branch.
3. Keep changes focused; add or update tests where appropriate.
4. Run the test suite and linters before opening a pull request.
5. Open a pull request describing your change.

## Development setup

```bash
pip install -e ".[dev]"
pytest
```
